# Google Pay – Digital Payments Analytics

## 1. Project Overview

This project focuses on analyzing Google Pay's digital payment system using SQL and database management concepts.

The dataset contains information about users, transactions, merchants, bank accounts, VPAs, bill payments, cities, disputes, and rewards.

## 2. Problem Statement

The objective of this project is to analyze digital payment transactions and understand user payment behavior, transaction performance, merchant performance, and payment failures.

The analysis will help identify transaction trends, successful and failed payments, high-value transactions, and overall payment patterns.

## 3. Project Objectives

- Analyze the total number of transactions.
- Identify successful, failed, reversed, refunded, and pending transactions.
- Calculate total transaction amount and average transaction value.
- Identify top-performing merchants.
- Analyze monthly transaction trends.
- Compare P2M and P2P transactions.
- Identify high-value transactions.
- Analyze user and merchant activity.

## 4. Dataset Description

The project uses the following tables:

1. Users – Stores user details and KYC information.
2. Transactions – Contains digital payment transaction records.
3. Merchants – Stores merchant information.
4. Bank Accounts – Contains linked bank account details.
5. VPAs – Stores virtual payment addresses.
6. Cities – Contains city information.
7. Bill Payments – Stores bill payment records.
8. Disputes – Contains transaction dispute details.
9. Rewards – Stores user reward information.

## 5. Key Business Questions

- What is the total number of transactions?
- What percentage of transactions are successful?
- Which transaction type has the highest volume?
- Which merchants generate the highest transaction amount?
- What are the monthly transaction trends?
- What are the most common transaction statuses?
- Which transactions have the highest amounts?
- How does user payment activity vary?

## 6. Key Performance Indicators (KPIs)

- Total Transactions
- Total Transaction Amount
- Successful Transaction Count
- Failed Transaction Count
- Transaction Success Rate
- Average Transaction Value
- Monthly Transaction Volume
- Top Merchant by Transaction Volume

## 7. Tools and Technologies

- PostgreSQL
- SQL
- Visual Studio Code
- CSV Dataset

## 8. Expected Outcome

The project aims to generate meaningful insights from digital payment data using SQL queries, aggregations, joins, and database analysis techniques.
